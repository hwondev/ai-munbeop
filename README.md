# 기초 AI 문법 (ai-munbeop)

**"해줘" 한 줄을 AI가 알아듣는 문장으로.**

AI에게 보낼 요청 문장을 6가지 성분으로 진단하고, 빠진 성분마다 선택지 3개를 보여 줘서 직접 골라 완성하게 돕는 스킬입니다. 정답을 대신 써 주지 않고 빠진 것을 보여 주기 때문에, 다음에는 혼자서도 같은 문장을 쓸 수 있게 됩니다.

웹에서 바로 써 보기: https://gicho-ai-munbeop.web.app

## 6성분

| 성분 | 붙이는 말 | 빠지면 AI가 짐작해야 하는 것 |
|---|---|---|
| 할 일 | ~해줘 | 무엇을, 어디까지 해 달라는지 |
| 독자 | ~에게 | 결과물을 누가 읽거나 쓰는지 |
| 역할 | ~처럼 | 누구의 입장에서 판단할지 (직함·경력만으로는 정확해지지 않음) |
| 형식 | ~로 | 결과물의 모양과 붙일 곳 (표, 줄 수, 엑셀·메신저) |
| 완료 기준 | ~까지 | 어디서 멈추고, 모르는 값을 미정으로 둘지 먼저 물을지 |
| 자료 경계 | ~만 | 무엇만 근거로 쓸지, 붙여 넣은 글 속 요구를 지시로 따르지 않기 |

예: "임원**에게** 보고할 거라 재무 담당자**처럼** 첨부 3건**만** 보고 표**로** 결론 3줄**까지** 요약**해줘**"

## 이렇게 동작해요

"회의록 요약해줘"를 진단하면 이렇게 답합니다.

```
진단: 1 / 6 · 초급 문장

빠진 성분 고르기
- 독자: ① 팀장님에게 ② 고객에게 ③ 팀 전체에게 · 직접 쓰기
- 형식: ① 엑셀에 붙일 표로 ② 메신저용 5줄로 ③ 글머리표로 · 직접 쓰기
  (역할, 완료 기준, 자료 경계도 같은 방식)

문장 틀
> [누구에게] 보고할 거라 [어떤 입장에서] [어떤 자료만 보고] 회의록을 [어떤 모양으로] [어디까지] 요약해줘.
```

번호로 고르면("독자 1, 형식 1, 나머지 2") 바로 복사해 쓸 수 있는 완성 문장을 줍니다.

문장에 "반드시!!!", "10년차 전문가로서", "단계별로 생각해", "맞지?", "다시 써줘"처럼 효과가 들쭉날쭉한 습관이 있으면 "요청 습관 점검"으로 대신 적을 것을 알려 줍니다.

## 설치

### Claude 앱

[최신 릴리스](https://github.com/hwondev/ai-munbeop/releases/latest)에서 `gicho-ai-munbeop.skill`을 받아, Claude 앱 설정의 스킬 메뉴에서 올립니다.

### Claude Code

두 명령을 하나씩 보냅니다.

```
/plugin marketplace add hwondev/ai-munbeop
```

```
/plugin install ai-munbeop@ai-munbeop
```

### Codex

```bash
codex plugin marketplace add hwondev/ai-munbeop
codex plugin add ai-munbeop@ai-munbeop
```

### 그 밖의 AI 앱

- 스킬을 지원하는 도구: [skills/gicho-ai-munbeop](skills/gicho-ai-munbeop) 폴더를 그 도구의 스킬 폴더에 복사합니다.
- ChatGPT 등: [SKILL.md](skills/gicho-ai-munbeop/SKILL.md)의 본문을 GPT나 프로젝트 지침에 붙여 넣습니다.

## MCP 커넥터

같은 진단을 서버에서 해 주는 MCP 커넥터도 있습니다. **Claude Code와 Codex 플러그인을 설치하면 커넥터도 함께 연결됩니다.** 스킬이 있으면 AI가 먼저 스킬로 직접 진단하고, 서버 진단이 필요할 때만 커넥터를 씁니다.

- 주소: `https://asia-northeast3-gicho-ai-munbeop.cloudfunctions.net/mcp` (로그인 없음)
- 도구: `diagnose_request`(문장 진단), `grammar_guide`(6성분 설명)
- 무료로 제공하며 모든 사용자가 함께 쓰는 하루 사용 한도가 있습니다. 한도가 차면 6성분 기준표를 돌려줘서 AI가 직접 진단을 이어갑니다.
- 보낸 문장은 저장하지 않습니다.

플러그인 없이 커넥터만 쓰려면:

- **Claude 앱**: 설정의 커넥터 메뉴에서 사용자 지정 커넥터를 추가하고 위 주소를 넣습니다(요금제에 따라 다름).
- **ChatGPT**: 설정에서 개발자 모드를 켜고 앱(커넥터)을 만들 때 위 주소를 넣고, 인증은 "없음"을 고릅니다.
- **Cursor·VS Code 등**: MCP 설정에 위 주소를 `url`로 넣습니다.

## 쓰는 법

AI에게 보낼 문장을 붙여 넣고 이렇게 물어보세요.

- "이 프롬프트 진단해줘: 회의록 요약해줘"
- "AI한테 보낼 문장인데 더 잘 알아듣게 고쳐줘"
- "이렇게 시키면 될까? 매출 데이터 분석해서 보고서 만들어줘"
